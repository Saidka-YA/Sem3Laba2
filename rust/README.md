# Лабораторная работа №2 на Rust

Это отдельная версия программы `LABA2`. Исходники C++ остаются в родительском каталоге.

## Сборка

Из каталога `rust`:

```bash
cargo build
```

Нужны Rust и Cargo. Если команда `cargo` отсутствует, сначала установите Rust через [rustup](https://rustup.rs/).

Запускать можно через `cargo run -- <команда>`. После сборки готовый файл находится в `target/debug/LABA2`.

## Команды

```bash
cargo run -- POSTFIX
cargo run -- GENOM
cargo run -- STRESS
cargo run -- HUFFMAN
cargo run -- MANAGER
cargo run -- LRU
cargo run -- --file data.json --query "SETADD apple"
```

Файловый режим создаёт отсутствующий JSON-файл с содержимым `[]`. Для множества доступны запросы `SETADD`, `SETDEL`, `SET_AT`; успешный запрос ничего не печатает. Можно передать несколько `--query` подряд. Хеш-таблица поддерживает линейное пробирование и двойное хеширование; отдельной команды для задания 6.1 нет, как и в C++ версии.

## Структура

- `src/main.rs` — только запуск интерфейса;
- `src/interface.rs` — чтение данных и команды;
- `src/algorithms/` — решения задач;
- `src/structures/` — стек, массив, множество, хеш-таблица.

Ввод в интерактивных режимах сопровождается приглашением `->`. Пример для LRU: первая строка `2 8`, далее восемь строк `SET 1 2` или `GET 1`.
