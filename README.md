# Лабораторная работа №2

Консольная программа `LABA2` объединяет задания по постфиксной записи,
множеству, сравнению геномов, проверке ударений, кодированию Хаффмана,
подсчёту подчинённых и LRU-кэшу.

## Сборка

Из каталога `Sem3Laba2`:

```bash
make
```

Нужны `g++` с поддержкой C++17 и файлы `json_file.h`, `json_file.cpp`
в соседнем каталоге `../Sem3Laba1`. Они подключаются без изменения исходного кода.
После сборки появляется `./LABA2`.

## Запуск

| Команда | Ввод после запуска | Результат |
| --- | --- | --- |
| `./LABA2 POSTFIX` | Одна строка с выражением, например `3+1*4` | Постфиксная запись и значение: `314*+ = 7` |
| `./LABA2 GENOM` | Две строки с геномами, например `ABBACAB` и `BCABB` | Одно число: `4` |
| `./LABA2 STRESS` | Число `N`, затем `N` слов словаря и строка текста | Число ошибок в ударениях |
| `./LABA2 HUFFMAN` | Одна строка текста | Строка из `0` и `1` |
| `./LABA2 MANAGER` | Число пар `N`, затем `N` строк вида `сотрудник менеджер` | Число подчинённых для каждого имени |
| `./LABA2 LRU` | Ёмкость `cap`, число запросов `Q`, затем `Q` запросов `SET x y` или `GET x` | Каждое значение `GET` на новой строке |

Во всех интерактивных режимах ввод сопровождается приглашением `->`.
Вычисление в `POSTFIX` рассчитано на выражения с однозначными числами.

Пример для менеджеров:

```text
5
A B
C B
D E
B E
E E
```

Результат: `A-0, B-2, C-0, D-0, E-4`.

Пример для LRU-кэша:

```text
2 8
SET 1 2
SET 2 3
SET 1 5
SET 4 5
SET 6 7
GET 4
SET 1 2
GET 3
```

Результат:

```text
5
-1
```

## Множество и JSON

Множество работает в файловом режиме:

```bash
./LABA2 --file data.json --query "SETADD apple"
./LABA2 --file data.json --query "SET_AT apple"
./LABA2 --file data.json --query "SETDEL apple"
```

Если `data.json` отсутствует, программа создаёт его с содержимым `[]`.
Родительский каталог файла должен существовать. Формат файла — JSON-массив
строк, например `["apple","banana"]`. Успешные файловые запросы ничего
не выводят. Можно передать несколько параметров `--query` за один запуск.

## Структура проекта

- `main.cpp` — только функция `main`;
- `src/` — реализация структур данных и консольного интерфейса;
- `headers/` — заголовочные файлы;
- `algorithms/` — решения заданий;
- `Makefile` — сборка программы.
